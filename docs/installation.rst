Installation
============

Pyjo-GCP is installed from `PyPI <https://pypi.org/project/Pyjo-GCP/>`_, with
:doc:`Pyjoyment <pyjoyment:installation>`, which it depends on: ::

    pip install Pyjo-GCP

or, in a project managed with `uv <https://docs.astral.sh/uv/>`_: ::

    uv add Pyjo-GCP

The development version is installed from the Git repository: ::

    pip install git+https://github.com/pyjoyment/Pyjo-GCP
